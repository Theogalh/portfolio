# portfolio

Projects showcase for theogalh.dev. Static HTML generated by `build.py`, served by GitHub Pages at
https://theogalh.github.io/portfolio/

Styling comes from the hosted design system
(`https://theogalh.github.io/design-system/styles.css`); only page-specific CSS is inlined.

## Layout

```
build.py                    page generator — one dict per project in PROJECTS
assets/avatar.webp          hero illustration, embedded as a data URI at build time
pages.workflow.yml          → move to .github/workflows/pages.yml (see setup)
dist/                       generated output, gitignored
```

## Build locally

```bash
python3 build.py
python3 -m http.server -d dist 8080
```

## One-time setup

1. `git mv pages.workflow.yml .github/workflows/pages.yml` — the file was committed from a
   token without the `workflow` scope, so it could not be placed there directly.
2. Add `assets/avatar.webp` (the build falls back to a relative path if it is missing).
3. Settings → Pages → Source: **GitHub Actions**.

Every push to `main` then rebuilds `dist/` and publishes it.
